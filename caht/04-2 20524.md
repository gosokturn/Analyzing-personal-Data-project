## 2. 앱에서 제공하는 기능

| 분석 항목 | 제공 기능 |
|---|---|
| 데이터 기본 정보 | 행 개수, 열 개수 |
| 데이터 품질 | 전체 결측치 개수와 비율, 열별 결측치 |
| 중복 데이터 | 중복 행 개수 및 일부 중복 행 확인 |
| 자료형 분석 | 열별 자료형과 고유값 개수 |
| 기초통계량 | 평균, 중앙값, 표준편차, 최솟값, 최댓값, 사분위수 |
| 데이터 시각화 | 히스토그램, 상자그림 |
| 결과 저장 | 기초통계량 CSV 다운로드 |

### 화면 구성

앱은 네 개의 탭으로 구성했어.

1. **데이터 미리보기:** 데이터의 구조와 실제 값을 확인해.
2. **결측치·자료형:** 결측치가 많은 열과 자료형을 확인해.
3. **기초통계량:** 평균, 중앙값, 표준편차 등 주요 통계량을 표로 보여 줘.
4. **분포 살펴보기:** 원하는 숫자형 열을 선택해 히스토그램과 상자그림을 확인해.

## 3. Streamlit Cloud에 배포하는 방법

### ① GitHub 저장소 만들기

GitHub에 새 저장소를 만들고 다음 두 파일을 올려 줘.

```text
저장소/
├── main.py
└── requirements.txt
```

### ② 데이터 주소 입력하기

앱은 데이터 파일을 직접 포함하는 대신, GitHub의 Raw CSV 주소를 입력받도록 만들었어.

예를 들어 주소는 다음과 같은 형태야.

`https://raw.githubusercontent.com/사용자명/저장소명/main/indexData.csv`

위 주소는 형식을 보여 주기 위한 예시이므로 실제 저장소 정보에 맞게 바꿔야 해.

### ③ Streamlit Cloud에서 배포하기

Streamlit Community Cloud에서 GitHub 저장소를 연결하고 실행 파일로 `main.py`를 지정하면 돼.

배포 후 왼쪽 입력창에 Raw CSV 주소를 넣고 **데이터 불러오기** 버튼을 누르면 분석이 시작돼.

## 4. 이번 탐구에서 특히 중요한 점

이번 앱은 단순히 데이터를 요약하는 것에서 끝나지 않아. 이후 급락 위험 분석으로 이어질 수 있도록 기초 데이터를 점검하는 역할을 해.

예를 들어 다음과 같은 순서로 탐구를 진행할 수 있어.

**1단계:** 전체 데이터의 행·열 개수와 결측치 확인

**2단계:** 종가(`Close`)의 중앙값, 평균, 표준편차 등 분석

**3단계:** 날짜별 종가 변화를 그래프로 확인

**4단계:** 일별 수익률과 최고점 대비 하락률을 계산해 급락 구간 탐색

**5단계:** 시장별 급락 폭과 회복 기간 비교

특히 **평균과 중앙값만으로 급락 위험을 판단할 수는 없다**는 점을 기억해야 해. 급락 위험을 구체적으로 분석하려면 일별 수익률과 최고점 대비 하락률 같은 지표를 추가해야 해.

이 앱은 그 분석을 시작하기 위한 첫 번째 단계야.

보내 준 GitHub Raw 주소를 `main.py`에 미리 입력해 수정했어! 이제 앱을 실행하면 **데이터 주소 입력창 없이 CSV 파일을 자동으로 불러와 기초통계를 분석**해. 📊

## 🚀 Streamlit에서 실행하기

1. 위 ZIP 파일을 다운로드하고 압축을 풀어.
2. 두 파일을 GitHub 저장소에 업로드해.
3. Streamlit Cloud에서 해당 저장소의 `main.py`를 실행 파일로 지정해.
4. 앱을 실행하면 데이터가 자동으로 로드돼.

**데이터 주소는 다음과 같이 코드에 고정되어 있어.**

```python
DATA_URL = "https://raw.githubusercontent.com/gosokturn/Analyzing-personal-Data-project/refs/heads/main/data/indexData.csv"
```

참고로 이번에는 코드를 수정하고 파일을 생성했지만, 실제 Streamlit 배포 환경에서 CSV를 정상적으로 읽어 오는지는 별도로 실행해 확인해야 해. 데이터 주소가 공개되어 있고 CSV 파일을 정상적으로 읽을 수 있어야 해.보내 준 GitHub Raw 주소를 `main.py`에 미리 입력해 수정했어! 이제 앱을 실행하면 **데이터 주소 입력창 없이 CSV 파일을 자동으로 불러와 기초통계를 분석**해. 📊
