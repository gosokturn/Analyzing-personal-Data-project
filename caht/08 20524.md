사진의 평가 기준을 보면, 현재 진행 중인 **세계 금융시장 분석 프로젝트에 적용할 수 있다.** 다만 지금까지 만든 화면만으로는 평가 기준을 모두 충족한다고 보기 어렵다. 특히 **기준선(Baseline)과 비교 모델 3개 이상의 성능을 같은 조건에서 수치로 비교하는 과정**을 추가해야 한다.

사진의 기준을 프로젝트에 맞게 해석하면 다음과 같다.

| 문제에 맞는 모델 선택   | 시장 유형을 나누는 문제는 군집화, 하락 위험을 예측하는 문제는 분류 |

## **4. 모델 평가 결과는 어떻게 분석하고 해석해야 할까?**

여기서 중요한 것은 단순히 가장 높은 점수를 받은 모델을 고르는 것이 아니다. **우리의 질문에 적합한 모델인지, 기준선보다 실제로 개선되었는지, 어떤 한계가 있는지**를 설명해야 한다.

### **① 하락 위험 분류 모델**

이번 프로젝트의 질문은 다음과 같다.

> 과거 금융시장 데이터를 바탕으로 다음 거래일에 큰 하락이 발생할지를 분류할 수 있는가?

평가 지표는 다음과 같이 해석하면 된다.

| 평가 지표   | 의미                     | 해석할 때 확인할 점           |
| ------- | ---------------------- | --------------------- |
| 정확도     | 전체 예측 중 맞힌 비율          | 하락 사례가 적으면 높게 나올 수 있음 |
| 정밀도     | 하락이라고 예측한 것 중 실제 하락 비율 | 하락 예측의 신뢰도            |
| 재현율     | 실제 하락 중 찾아낸 비율         | 하락 사례를 얼마나 놓치지 않았는지   |
| F1      | 정밀도와 재현율의 조화평균         | 두 지표의 균형              |
| ROC-AUC | 두 범주를 구별하는 능력          | 0.5에 가까우면 무작위 구분 수준   |

예를 들어 다음과 같은 결과가 나왔다고 가정해 보자. 아래 숫자는 설명을 위한 가상 예시이며 실제 프로젝트 결과가 아니다.

| 모델      | 정확도  | 정밀도  | 재현율  | F1   |
| ------- | ---- | ---- | ---- | ---- |
| 기준선     | 0.90 | 0.00 | 0.00 | 0.00 |
| 로지스틱 회귀 | 0.85 | 0.40 | 0.60 | 0.48 |
| 랜덤 포레스트 | 0.88 | 0.55 | 0.45 | 0.49 |
| 부스팅     | 0.87 | 0.50 | 0.55 | 0.52 |

이 경우 기준선의 정확도가 가장 높지만, 실제 하락 사례는 하나도 찾아내지 못한다.

반면 부스팅 모델은 정확도가 기준선보다 낮아도 F1과 재현율에서 더 나은 결과를 보여 준다.

따라서 하락 위험을 찾는 것이 목적이라면 정확도만 보고 기준선을 선택하는 것은 적절하지 않다.

### **② 시장 유형 군집화 모델**

군집화는 정답이 미리 존재하지 않으므로 분류 모델과 평가 방법이 다르다.

| 평가 지표             | 좋은 방향   | 해석                            |
| ----------------- | ------- | ----------------------------- |
| 실루엣 점수            | 높을수록 좋음 | 같은 그룹끼리 가깝고 다른 그룹과 멀리 떨어져 있는가 |
| Davies-Bouldin    | 낮을수록 좋음 | 그룹 간 분리와 그룹 내부 응집도가 양호한가      |
| Calinski-Harabasz | 높을수록 좋음 | 그룹 간 분산이 그룹 내부 분산보다 큰가        |

단, 군집화 점수가 높다고 반드시 경제적으로 의미 있는 그룹이 만들어진 것은 아니다. 실제 그룹에 어떤 시장이 포함됐는지, 각 그룹의 평균 수익률과 변동성도 함께 살펴봐야 한다.

### **③ 보고서에 작성할 때의 순서**

모델 평가 결과를 확인한 뒤 다음 순서로 정리하면 좋다.

1. **기준선 설명:** 아무런 복잡한 패턴 학습 없이 어떤 결과를 예측하는가?
2. **모델 비교:** 어떤 후보 모델을 같은 조건에서 비교했는가?
3. **수치 비교:** 기준선과 비교해 어떤 평가 지표가 얼마나 변했는가?
4. **최종 선택:** 어떤 모델을 선택했고, 우리 질문에 왜 적합한가?
5. **한계:** 어떤 상황에서 예측이 틀릴 수 있으며, 결과를 어디까지 믿을 수 있는가?

### 모델 평가 및 결과 해석

본 프로젝트에서는 다음 거래일의 큰 하락 여부를 예측하는 분류 모델을 제작하였다.

모델의 성능을 객관적으로 비교하기 위해 다수 범주 예측을 기준선으로 설정하고, 로지스틱 회귀, 랜덤 포레스트, 히스토그램 기반 부스팅 모델을 비교하였다.

모든 모델은 동일한 입력 변수와 시간 순서를 유지한 학습·테스트 데이터 분할 조건에서 평가하였다.

평가 지표로는 정확도, 정밀도, 재현율, F1 점수를 사용하였다. 특히 하락 사례를 얼마나 놓치지 않고 찾아내는지를 확인하기 위해 재현율을 함께 분석하였다.

실제 평가 결과를 바탕으로 기준선보다 성능이 개선된 모델이 있는지 확인하고, 최종 모델의 장점과 한계를 해석하였다.

**마지막으로 중요한 점:** 지금 통합한 코드는 기존 기능을 보존하고 평가 절차를 추가한 구조다. 실제 모델 평가 결과는 Streamlit에서 실행한 뒤 확인해야 한다. 결과를 확인할 때는 기준선보다 점수가 높다는 사실만 적지 말고, 그 차이가 우리 질문에 어떤 의미를 갖는지 설명하는 것이 핵심이다.






먼저 데이터 전처리부터 설명할게. **현재 코드에서는 전처리가 자동으로 실행된다.** 데이터를 직접 선택해서 각 전처리 작업을 하나씩 실행하는 방식은 아니다.

다만 자동 처리되는 항목과 사용자가 선택할 수 있는 항목이 구분되어 있다.

## **1. 현재 전처리 방식 분석**

### **그런데 한 가지 주의할 점이 있어**

현재 `main.py`에서는 다음처럼 실행하고 있다.

```
clean, price_col, audit = prepare_market_data(raw, winsorize=False)
```

즉, 데이터 전처리 페이지에서 '극단값 완화'를 선택하더라도 **모델 설계·평가 페이지에는 그 선택이 전달되지 않는다.** 모델 페이지는 항상 `winsorize=False`로 다시 전처리한다.

따라서 지금은 전처리 페이지에서 설정을 바꿔도 모델 평가 결과에는 반영되지 않는 구조다.

내 판단으로는 현재 기본 설정인 극단값 유지가 금융 데이터 분석에 합리적이다. 실제 급락을 단순 이상치로 판단해 줄이면 위험성이 과소평가될 수 있기 때문이다. 따라서 지금 당장 전처리 코드를 바꿀 필요는 없지만, 두 페이지의 설정이 서로 다르게 보일 수 있다는 점은 알고 있어야 한다.

## **2. 모델 평가 오류 원인**

올려 준 오류를 확인했다.

문제는 `main.py`의 다음 부분이다.

```
"계층적 군집화": AgglomerativeClustering(n_clusters=k),"가우시안 혼합 모델": GaussianMixture(n_components=k, random_state=42, n_init=5)
```

그런데 파일 상단에서 이 두 모델을 불러오지 않았다.

- `AgglomerativeClustering`: 계층적 군집화 모델
- `GaussianMixture`: 가우시안 혼합 모델

따라서 `NameError`가 발생한 것이다.

그리고 네가 올린 두 오류 내용은 실제로는 **동일한 오류 메시지가 반복해서 표시된 것**이다. 기준선 탭 자체의 오류라는 별도 traceback은 아직 확인되지 않았다.

기준선 탭에서도 오류가 나타난 이유는 Streamlit의 `st.tabs()`가 탭을 선택할 때만 코드를 실행하는 방식이 아니기 때문이다. 한 탭에서 오류가 발생하면 같은 페이지의 다른 탭도 정상적으로 확인하기 어려워진다.
